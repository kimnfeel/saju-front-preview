# 착한사주 — 프론트 네비게이션 미리보기

이 저장소는 **화면 이동(네비게이션) 확인용 정적 미리보기**입니다.

- 사주 계산·판정·AI 해설 등 **백엔드/엔진/지침 소스는 포함되지 않습니다.**
- 해설 본문은 **자리표시자**로 대체되어 있고, 데이터는 샘플(테스트 프로필)입니다.
- 목적: 홈 → 메뉴 → 프로필 선택 → 기록/고민입력/무료운세 진입 → 결과, 하단 탭 등 **흐름만** 확인.

## 보기
- GitHub Pages: 저장소 Settings → Pages에서 활성화된 주소로 접속
- 또는 `index.html`을 브라우저로 직접 열기
